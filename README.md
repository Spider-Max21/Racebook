# Racebook

Version **1.4.0** – lokales Wartungs- und Werkstattheft für Motorräder als Progressive Web App.

App: https://spider-max21.github.io/Racebook/

Daten werden auf dem Gerät gespeichert. Die Texterkennung verwendet mitgelieferte lokale OCR-Dateien; Fotos werden dafür nicht an externe Dienste übertragen.

Dieses Repository enthält ausschließlich die veröffentlichte App und die Lizenzhinweise der mitgelieferten Komponenten.
